# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within VolcanStorage, please report it privately by opening a [Security Advisory](https://github.com) on the repository or contacting the maintainers directly.

Please do not disclose security issues through public GitHub issue trackers until they have been reviewed and patched.
