# Support

## How to Get Help and Report Issues

This project uses [GitHub Issues](https://github.com) for tracking bug reports and feature suggestions:

1. **Before filing an issue**: Search existing issues and discussions to see if the topic has already been addressed.
2. **Filing an issue**: Provide clear reproduction steps, hardware specifications (GPU, OS version, Vulkan SDK version), and compiler details.

For questions, community discussions, and architectural proposals, please use GitHub Discussions.
